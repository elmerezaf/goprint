# GoPrint 备份与还原指南

## 快速开始

我为你创建了两个一键备份还原脚本，让你轻松保护你的网站数据。

### 📦 备份脚本
**文件位置：** `C:\xampp\htdocs\goprint\backup.bat`

**功能：**
- ✅ 自动备份数据库（goprint_db）
- ✅ 自动备份所有网站文件
- ✅ 自动创建时间戳命名的备份文件夹
- ✅ 备份位置：`C:\xampp\backups\goprint\`

**使用方法：**
1. 双击运行 `backup.bat`
2. 等待备份完成
3. 备份完成后会自动打开备份文件夹

---

### 🔄 还原脚本
**文件位置：** `C:\xampp\htdocs\goprint\restore.bat`

**功能：**
- ✅ 显示所有可用备份列表
- ✅ 选择要还原的备份版本
- ✅ 自动清空并重建数据库
- ✅ 还原所有网站文件

**使用方法：**
1. 双击运行 `restore.bat`
2. 选择要还原的备份编号
3. 确认还原操作
4. 等待还原完成

---

## ⚠️ 重要提示

### 使用还原功能前：
1. **务必三思而后行！** 还原操作会覆盖当前所有数据
2. 建议先运行一次备份，确保有最新的备份
3. 确认你要还原的备份版本是正确的

### 备份存放位置：
- 备份文件夹：`C:\xampp\backups\goprint\`
- 每个备份都按时间戳命名（如：`2026-05-16_10-30`）
- 包含内容：
  - `database.sql` - 数据库备份
  - `website\` - 网站文件备份
  - `backup_info.txt` - 备份信息

### 备份频率建议：
- 🔴 **重要修改前**：一定要备份
- 🟡 **每周一次**：定期备份
- 🟢 **每天一次**：如果网站经常更新

---

## 🎯 推荐工作流程

### 场景1：修改重要功能前
```
1. 运行 backup.bat 创建备份
2. 开始修改代码
3. 如果出现问题，运行 restore.bat 还原
```

### 场景2：定期保护数据
```
1. 每周运行一次 backup.bat
2. 保留最近 4 周的备份
3. 每月检查备份是否正常
```

### 场景3：多人协作
```
1. 每次重要更新前备份
2. 记录备份时间和内容
3. 问题发生时快速还原
```

## ❓ 常见问题

**Q: 备份需要多长时间？**
A: 取决于网站大小，通常几秒到几分钟不等。

**Q: 备份文件可以删除吗？**
A: 可以，但建议保留最近的几个备份版本。

**Q: 还原失败怎么办？**
A: 检查是否正在使用数据库，确保 XAMPP MySQL 服务正在运行。

**Q: 可以备份到其他位置吗？**
A: 可以，但需要修改脚本中的 `BACKUP_DIR` 变量。

## 📝 手动备份（可选）

如果脚本出现问题，你也可以手动备份：

**备份数据库：**
```bash
cd C:\xampp\mysql\bin
mysqldump.exe -u root --password= goprint_db > backup.sql
```

**备份文件：**
```bash
xcopy C:\xampp\htdocs\goprint D:\备份位置 /E /I
```
