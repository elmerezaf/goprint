# GoPrint Project Overview

Printing service e-commerce website for Gift and Premium Enterprise Limited

## Project Information

- Developer: Elmer So
- Company: Gift and Premium Enterprise Limited
- Website: goprint.com.hk
- Development period: April 2026 - May 2026
- Current Phase: Phase 19 - Database Backup & Recovery System

## Folder Structure

```
01_Documentation/          # Development logs & reports
02_Code/                   # Project source code
  01_Database/            # SQL files
  02_MVC/                # Custom MVC prototype
  wordpress/              # WordPress theme files
  goprint-child/          # WordPress child theme
  laravel/                # Laravel product system
    resources/lang/      # Multi-language translation files
    database_backups/     # Automated backup storage
03_Screenshots/           # Screenshot record of each phase
```

## Technology Stack

- Frontend: HTML, CSS, JavaScript, Bootstrap 5
- Backend: PHP 8.1+, WordPress 6.x, Laravel 10.x
- Database: MySQL 8.x
- Server: Apache 2.4 (via XAMPP)
- Version Control: Git
- Localization: Laravel i18n (English, Traditional Chinese, Simplified Chinese)
