# GoPrint 水印移除工具 - 使用说明

## 📖 简介
这是一个专业的水印移除工具，使用 **OpenCV Inpainting** 技术（类似 Photoshop 的内容感知填充），可以智能地移除图片右下角的水印。

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）
1. 双击 `启动水印移除工具.bat`
2. 脚本会自动检查并安装所需依赖
3. GUI 界面会自动打开

### 方法二：创建桌面快捷方式
1. 双击 `创建桌面快捷方式.bat`
2. 桌面会生成 "GoPrint水印移除工具" 快捷方式
3. 以后直接双击桌面快捷方式即可使用

### 方法三：直接运行 Python
```bash
python watermark_remover_gui.py
```

## 🎨 功能特性

### 1. 添加图片
- **选择图片**：点击按钮选择单个或多个图片文件
- **选择文件夹**：批量选择整个文件夹中的所有图片
- **拖放**：直接将图片或文件夹拖放到窗口中

### 2. 水印位置设置
- **从右边距 (%)**：水印距离图片右边的百分比（默认 18%）
- **从下边距 (%)**：水印距离图片下边的百分比（默认 15%）
- 根据你的水印位置调整这些参数

### 3. 开始处理
1. 确认文件列表正确
2. 调整水印位置参数（如需要）
3. 点击 "🚀 开始处理" 按钮
4. 等待处理完成，查看日志

## 📋 技术细节

### 依赖库
- **opencv-python**：用于图像处理和 Inpainting
- **numpy**：数值计算
- **tkinterdnd2**（可选）：拖放支持

### Inpainting 算法
工具同时使用两种 Inpainting 算法并混合结果：
- **Telea**（快速，适合纹理）
- **Navier-Stokes**（慢速，适合结构）

## 💡 建议

1. **备份原图**：处理前建议备份原始图片
2. **调整参数**：如果水印位置不同，调整边距百分比
3. **批量处理**：可以一次性处理整个文件夹的数百张图片

## 📁 文件说明
- `watermark_remover_gui.py` - GUI 主程序
- `启动水印移除工具.bat` - 一键启动脚本
- `创建桌面快捷方式.bat` - 创建桌面快捷方式
- `professional_watermark_remover.py` - 专业版命令行工具
- `remove_watermark.py` - 简单版命令行工具
