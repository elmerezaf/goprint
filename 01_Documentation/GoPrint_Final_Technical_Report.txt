1. Project Overview
===========================================

GoPrint is a printing service e-commerce website developed for Gift and Premium Enterprise Limited.

4. Deployment Instructions
===========================================

4.1 Docker One-Click Deployment
-------------------
Requirements:
- Docker 20.10+
- Docker Compose 2.0+

Deployment Steps:
1. Enter project directory
2. Run deployment script:
   - Linux/Mac: ./deploy.sh
   - Windows: deploy.bat

4.2 Manual Deployment
-------------------
1. Configure web server (Apache/Nginx)
2. Set up PHP 8.1+ environment
3. Create MySQL database
4. Copy .env.example to .env and configure
5. Run database migration: php artisan migrate
6. Create storage link: php artisan storage:link
7. Generate application key: php artisan key:generate

4.3 Environment Variables
-------------------
Key Configuration:
- APP_KEY: Application encryption key
- DB_HOST/DATABASE/USERNAME/PASSWORD: Database configuration
- STRIPE_KEY/STRIPE_SECRET: Payment keys

5. API Endpoints
===========================================

5.1 Authentication Endpoints
-------------------
POST /api/login - User Login
POST /api/logout - User Logout
POST /api/register - User Registration

5.2 Product Endpoints
-------------------
GET /api/products - Get product list
GET /api/products/{id} - Get product detail
GET /api/categories - Get category list

5.3 Order Endpoints
-------------------
GET /api/orders - Get user orders
GET /api/orders/{id} - Get order detail
POST /api/orders - Create order

Authentication: Bearer Token (Laravel Sanctum)
