# GoPrint Hong Kong Printing E-commerce Platform
## Final Technical Report

---

## 1. Project Overview

### 1.1 Project Background
GoPrint is a comprehensive e-commerce platform developed for Gift and Premium Enterprise Limited, a professional printing service company based in Hong Kong. The platform integrates WordPress CMS with Laravel framework to provide a robust online printing service solution.

### 1.2 Objectives
- Establish a professional online presence for printing services
- Provide customers with easy product browsing and ordering experience
- Implement multi-language support for diverse customer base
- Build secure and scalable backend management system
- Ensure data integrity with automated backup system

### 1.3 Project Timeline
- Development Period: April 2026 - May 2026
- Total Phases: 19

## 3. Database Design

### 3.1 Database Schema

**Product Table**
| Field | Type | Description |
|-------|------|-------------|
| pro_id | INT | Primary Key, Auto Increment |
| pro_name | VARCHAR(255) | Product Name |
| pro_desc | TEXT | Product Description |
| pro_price | DECIMAL | Product Price |
| pro_image | VARCHAR(255) | Image Path |
| cat_id | INT | Foreign Key to Category |
| create_time | TIMESTAMP | Creation Time |

**Category Table**
| Field | Type | Description |
|-------|------|-------------|
| cat_id | INT | Primary Key, Auto Increment |
| cat_name | VARCHAR(100) | Category Name |
| cat_desc | TEXT | Category Description |

**Users Table**
| Field | Type | Description |
|-------|------|-------------|
| id | BIGINT | Primary Key, Auto Increment |
| name | VARCHAR(255) | User Name |
| email | VARCHAR(255) | Email Address |
| password | VARCHAR(255) | Hashed Password |
| role | VARCHAR(20) | User Role (admin/user) |
| created_at | TIMESTAMP | Creation Time |

**Orders Table**
| Field | Type | Description |
|-------|------|-------------|
| id | BIGINT | Primary Key, Auto Increment |
| user_id | BIGINT | Foreign Key to Users |
| status | VARCHAR(20) | Order Status |
| total_amount | DECIMAL | Total Amount |
| created_at | TIMESTAMP | Creation Time |

**Addresses Table**
| Field | Type | Description |
|-------|------|-------------|
| id | BIGINT | Primary Key, Auto Increment |
| user_id | BIGINT | Foreign Key to Users |
| phone | VARCHAR(20) | Phone Number |
| city | VARCHAR(100) | City |
| district | VARCHAR(100) | District |
| address_detail | TEXT | Address Detail |
| is_default | BOOLEAN | Default Address Flag |

### 3.2 Entity Relationship Diagram

users 1 ─── * addresses
category 1 ─── * product
orders 1 ─── * order_items

## 4. Key Features Implementation

### 4.1 Multi-language Support (i18n)

**Implementation Details:**
- Three language locales: English (en), Traditional Chinese (zh-HK), Simplified Chinese (zh-CN)
- Session-based language storage
- Translation files located in `resources/lang/{locale}/messages.php`
- Language switcher dropdown in navigation bar
- Route: `/locale/{locale}` with name `setlocale`

**Translation File Structure:**
```
resources/
└── lang/
    ├── en/
    │   └── messages.php
    ├── zh-HK/
    │   └── messages.php
    └── zh-CN/
        └── messages.php
```

### 4.2 User Authentication

**Features:**
- User registration with email verification
- Secure login/logout
- Password reset functionality
- Role-based access control (admin/user)
- Password hashing using bcrypt

### 4.3 Shopping Cart System

**Implementation:**
- Session-based cart storage
- Add/remove/update cart items
- Cart item quantity management
- Real-time cart count display
- Cart persistence across sessions

### 4.4 Order Management

**Order Status Flow:**
```
Pending → Processing → Shipping → Completed
       ↘ Cancelled
```

**Features:**
- Order creation from cart
- Order confirmation with summary
- Order history viewing
- Admin order management
- Email notifications

### 4.5 Admin Panel

**Admin Features:**
- Dashboard with statistics overview
- Product CRUD operations
- Category management
- Order management with status updates
- Data analytics and reports
- Image upload functionality

### 4.6 Database Backup System

**Automated Backup:**
- Batch script for one-click backup
- Timestamped backup files (goprint_db_backup_YYYYMMDD_HHmmss.sql)
- Error handling with user feedback
- Backup storage directory: `database_backups/`
